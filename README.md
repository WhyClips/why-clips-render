# The Senator Who Sued God — Why Clips Short

Gullak Tales style Remotion Short (1080x1920, 30fps, 2168 frames / 72.27s).

Ernie Chambers, Nebraska state senator, filed a real lawsuit against God in
September 2007. The court held a hearing — nobody showed up. Judge Marlon
Polk dismissed it in October 2008, not because it was silly, but because God
has no home address on file, so the lawsuit could never be legally delivered.
