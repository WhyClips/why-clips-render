# Segway Short — Why Clips (Gullak)

Remotion project for "The Man Who Owned Segway Died Riding One" (Jimi Heselden, 2010) — Why Clips Short.
Gullak Tales chibi 2D style, pure SVG/DOM, 1080x1920 @ 30fps, 1800 frames (60.000s).
Built 27–28 Nov 2026 in the Fruit Flies / Moon Trees Gullak pipeline.
Render via GitHub Actions workflow `.github/workflows/render-segway-gullak.yml`
(branch: segway-gullak). See BUILD-NOTES.md.
