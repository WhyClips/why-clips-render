# three.js render test (Phase 0)

Minimal from-scratch three.js scene in Remotion (own code — no skill code):
a painted 3D street, houses, tree, stickman card, spinning sign, dolly-in
camera. 30 frames at 1080x1920, rendered on GitHub Actions to prove
three.js/WebGL works in headless Chrome (SwiftShader) before the rebuild.

Run: Actions tab > "Render Three.js Test" > Run workflow (branch `threejs-test`).
